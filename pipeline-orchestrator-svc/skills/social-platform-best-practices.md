# Social Media Best Practices

## LinkedIn
- Open with a bold statement or surprising statistic to stop scrolling
- Use line breaks between paragraphs for readability
- Include a question at the end to drive comments
- Tag relevant people or companies when appropriate
- Best posting times: Tuesday-Thursday, 8-10 AM

## Twitter/X
- Front-load the key message — most users only read the first line
- Use numbers and data points for higher engagement
- Keep threads concise — 3-5 tweets maximum
- One strong hashtag outperforms many weak ones

## Facebook
- Write conversationally — Facebook rewards authentic, personal content
- Ask open-ended questions to boost comment engagement
- Use emojis sparingly to add visual breaks
- Include a clear call-to-action (comment, share, visit link)

## Instagram
- Start with a hook line that creates curiosity
- Use short paragraphs with line breaks for readability
- Place hashtags at the end, separated by line breaks
- Include a strong CTA ("Save this post", "Share with a friend")
- Mix branded hashtags with discovery hashtags (10-15 total)

## Cross-Platform Rules
- Never copy-paste the same content across platforms — adapt for each
- Match the content length to platform norms
- Prioritize native content over link-sharing where possible
