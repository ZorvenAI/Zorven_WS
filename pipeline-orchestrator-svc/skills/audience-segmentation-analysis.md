# Audience Segmentation & Journey Mapping

**Priority**: 9
**Trigger**: audience_persona node with journey mapping or segmentation focus

## Segmentation Strategy

### Segmentation Dimensions

1. **Firmographic** (B2B): Company size, industry, revenue, growth stage, geography
2. **Demographic** (B2C): Age, gender, income, education, location, occupation
3. **Behavioral**: Purchase frequency, brand loyalty, channel preference, price sensitivity
4. **Psychographic**: Values, interests, lifestyle, personality traits, media consumption
5. **Needs-based**: Primary pain points, desired outcomes, urgency level

### Segment Prioritization Criteria

- **Market size**: Estimated segment size and growth rate
- **Revenue potential**: Average deal size or customer lifetime value
- **Accessibility**: How reachable through available channels
- **Competitive intensity**: Number of competitors actively targeting this segment
- **Strategic fit**: Alignment with brand positioning and capabilities

## Buying Journey Framework

### Default 6-Stage Model

1. **Awareness**: Prospect recognizes a problem or opportunity
2. **Consideration**: Prospect researches possible solutions and approaches
3. **Evaluation**: Prospect compares specific vendors/products
4. **Decision**: Prospect selects a solution and negotiates terms
5. **Onboarding**: New customer implements and begins using the solution
6. **Advocacy**: Satisfied customer refers others and expands usage

### Per-Stage Analysis

For each stage, identify:
- **Touchpoints**: Where and how the persona interacts with the brand
- **Information needs**: What questions they need answered
- **Emotional state**: Their feelings and concerns at this stage
- **Decision criteria**: What factors matter most
- **Objections**: Common barriers and hesitations
- **Content recommendations**: What content types and topics would be most effective

## Output Format

- Segment matrix comparing all personas across key dimensions
- Priority ranking with scoring methodology
- Journey timeline visualization data for each persona
